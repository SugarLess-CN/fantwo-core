## 六、明确不引入（避免过度工程）

- casbin：权限模型只有「用户-角色-权限点」三级，GORM 三表关联 + 内存判断足够，不引策略引擎。
- kratos/go-zero 等微服务框架：单体重构，gin 即可。
- protobuf/grpc：对外 HTTP + 内部无需 RPC。
- socket.io 兼容层：自研 WS hub 覆盖事件面（见二节）。

## 七、迁移关键结论

1. **bcrypt 保留**：新库无存量密码，直接 bcrypt（cost 10）生成；如未来导入旧用户，Node bcrypt 的 `$2a$/$2b$` 哈希可被 Go x/crypto/bcrypt 直接校验。
2. **TypeORM → GORM**：实体命名保持 snake_case 表名/列名；软删列（deleted_at）用 soft_delete 插件对齐；PostgreSQL 下序列/自增由 GORM AutoMigrate 处理，无需手写 DDL。
3. **Bull → asynq**：三个队列（image-audit / text-audit / video-compression）各自映射一个 asynq queue，重试次数/退避策略按原仓库配置平移。
4. **Socket.io → gorilla/websocket**：事件面为私信/通知，自研 hub + JSON 事件帧即可；前端需改连 WS（重构范围声明内）。
5. **支付回调**：smartwalle/alipay 与 wechatpay-go 均自带验签；回调幂等用订单号 + 状态机事务，语义对齐原仓库。

## 八、补充：图片水印字体

- **字体**：Noto Sans SC（Regular）子集，**SIL Open Font License 1.1（OFL-1.1）**
  - 原始字体 8.1 MB → 子集化后 **1.6 MB**（`internal/service/infra/assets/watermark.otf`），覆盖 ASCII + 中文标点 + GB2312 一二级全部 6763 汉字，共 6891 字符
  - 子集化工具：fontTools `pyftsubset`（`--no-hinting --desubroutinize --recalc-bounds`）
  - 版权与许可原文见 `internal/service/infra/assets/LICENSE-NotoSansSC.md`（OFL 要求随字体保留版权声明）
- **渲染**：`golang.org/x/image/font/opentype`（v0.48.0）+ `font.Drawer`
  - 选型说明：2019 版 x/image 的 `opentype.Face.Glyph` 是 `panic("not implemented")` 空实现，无法绘制文字，故升级该依赖；未采用 freetype-go（CGO 依赖）或 bimg（需 libvips）
  - 水印参数（模板/位置/透明度/字号）存 config 表，运行期可改，不必重新发版
