# 05 · 运行时配置项清单（config 表）

> 来源：payment 域（T-05f）实现的支付/审核/佣金配置读取逻辑，与原 NestJS 仓库 `config` 表的 key 对齐。
> 这些 key 存在数据库 `config` 表（key-value），不在环境变量里（对齐原仓库语义：支付凭据存 DB）。
> 由配置域（infra）提供 `/config` 系列接口读写，运维通过管理端写入。

## 一、支付渠道（支付宝）

| key | 说明 |
|---|---|
| `alipay_enabled` | 是否启用，`true`/`false` |
| `alipay_app_id` | 支付宝应用 AppID |
| `alipay_private_key` | 应用私钥（PKCS8） |
| `alipay_public_key` | 支付宝公钥（验签回调用） |
| `alipay_gateway` | 网关地址，如 `https://openapi.alipay.com/gateway.do` |

## 二、支付渠道（微信支付 v3）

| key | 说明 |
|---|---|
| `wechat_enabled` | 是否启用 |
| `wechat_app_id` | 公众号/App AppID |
| `wechat_mch_id` | 商户号 |
| `wechat_private_key` | 商户私钥（apiclient_key.pem 内容） |
| `wechat_serial_no` | 商户证书序列号 |
| `wechat_api_v3_key` | APIv3 密钥（回调解密用） |

## 三、支付渠道（易支付 epay）

| key | 说明 |
|---|---|
| `epay_enabled` | 是否启用 |
| `epay_app_id` | 商户 ID（pid） |
| `epay_app_key` | 商户密钥（key，MD5 签名用） |
| `epay_gateway` | 提交网关地址 |
| `epay_notify_url` | 异步通知地址 |

## 四、支付通用

| key | 说明 |
|---|---|
| `payment_notify_url` | 统一异步回调基址 |
| `payment_return_url` | 支付完成同步跳转地址 |

## 五、佣金分成（对齐原 commission.service）

| key | 默认 | 说明 |
|---|---|---|
| `commission_inviter_rate` | 0.05 | 邀请人分成比例（5%） |
| `commission_platform_rate` | 0.10 | 平台抽成比例（10%） |
| `commission_author_rate` | 0.85 | 作者分成比例（85%） |

## 六、内容审核（双 provider）

| key | 说明 |
|---|---|
| `content_audit_provider` | `aliyun` / `tencent` |
| `content_audit_comment_enabled` | 评论审核开关 |
| `content_audit_avatar_enabled` | 头像审核开关 |
| `content_audit_image_enabled` | 图片审核开关 |
| `content_audit_article_enabled` | 文章审核开关 |
| `content_audit_auto_block` | 命中即拦截（不转人工） |
| `content_audit_review_mode` | 人工复审模式 |

## 七、腾讯云（内容审核 provider 之一）

| key | 说明 |

| `tencent_text_biz_type` | 文本审核 BizType |

## 八、阿里云（内容审核 provider 之一）

| key | 说明 |

## 九、会员（`/order/membership` 会员充值订单）

| key | 说明 |
|---|---|
| `membership_price` | 默认会员价格（分） |
| `membership_name` | 会员名称 |
| `membership_price_1m` | 1 个月价格 |
| `membership_price_3m` | 3 个月价格 |

## 十、上线注意

1. **微信支付回调验签**依赖 `downloader.MgrInstance()` 平台证书缓存；首次回调若无缓存会报错（SDK 语义）。建议启动时预热证书，或容忍一次失败后重试。
2. **微信 v3 Native 下单**响应不含 `prepay_id`（SDK 只给 `code_url`），`payments.details.prepayId` 留空属预期行为。
3. **阿里云 green** 默认走国内站 endpoint；国际站账号需调整 `aliyun_region`。
4. **订单号规则**：`ORDER + 毫秒时间戳 + 3 位随机`（对齐原仓库，非严格唯一，靠 DB uniqueIndex 兜底）。
