# 接口入参协议枚举

> **前端提交表单/请求体时的取值参照表。** 每个枚举都标注了**代码里的权威来源**（`model/*.go` 的常量），
> 不是凭接口名字猜的。
>
> 快照：2026-11-27　｜　依据：`internal/model/*.go` 常量 + `binding:"oneof=..."` 校验 + handler 实际比较逻辑

---

## 零、先看这三类

入参里的 string 字段有 444 个，但**真正需要枚举的只有 40 来个**。分三类：

| 类别 | 特征 | 例 | 是否需要枚举 |
|---|---|---|---|
| **真枚举** | 有 `model` 常量定义 + service 层做 `!=` 比较 | `article.status` / `report.type` | ✅ 本文覆盖 |
| **自由文本** | 用户输入内容，无取值范围 | `reason` / `description` / `nickname` | ❌ 不限 |
| **ID 引用** | 是别的实体的主键 | `category_id` / `order_id` | ❌ 不限（但需存在性校验） |

**判定口诀**：代码里有没有 `if x != "A" && x != "B"` 或 `oneof=A B` 这样的比较。
有 → 枚举；没有 → 自由文本。

## 三、大小写不一致汇总（最容易踩的地方）

| 组别 | 风格 | 涉及字段 |
|---|---|---|
| **全大写** | `UPPERCASE` | `article.status/type`（type 除外）· `report.*` · `cert.*` · `order.*` · `payment.method` · `invite.*` · `achievement.type` · `decoration.type/obtain/status` · `category.status` · `user.status` |
| **全小写** | `lowercase` | `gender` · `banner.status` · `emoji.type/status` · `config.type` · `audit.action/source` · `oauth.provider/channel` · `article.type`（`image`/`mixed`/`video`） |
| **首字母大写** | `Mixed` | 无 |

**没有 `PascalCase` 或 `camelCase` 的枚举值** —— 都是「全大写」或「全小写」两派。

**建议前端**：不要用「统一转大写/小写」来兼容 —— 直接按本文取值传，
因为 `gender=male` 转成 `MALE` 会被拒绝。

## 四、批量声明建议（可选）

本文列出的 20 个未声明字段，建议在 DTO 上补 `enums:` 注解（不改代码逻辑，只改文档）：

```go
// PATCH /user/certification/admin/applications/{id}/audit
type AuditCertificationRequest struct {
    Status string `json:"status" enums:"APPROVED,REJECTED" example:"APPROVED"`
    Reason string `json:"reason" example:"材料齐全"`
}
```

**收益**：swagger/Apifox 侧会显示下拉选项，前端不用读文档。
**成本**：约 20 行注解。
**风险**：`enums:` 只是文档标注，**不产生运行时校验**。要真校验得用 `binding:"oneof=..."`。

### 建议加强校验的两处（高价值）

| 字段 | 现状 | 建议 |
|---|---|---|
| `cert.type` | 无校验，service 层 `if != OFFICIAL && != CREATOR` 才报错 | 加 `oneof=OFFICIAL CREATOR`，错误更早更准 |
| `report.category` | 无校验 | 加 `oneof=SPAM ABUSE INAPPROPRIATE COPYRIGHT OTHER` |

这两处是「用户传错要到 service 层才报错」的典型，加了能在绑定阶段就拦下。

## 五、自查命令

```bash
# ① 所有已声明的 oneof（权威校验）
grep -rn 'binding:"[^"]*oneof=' internal/dto/*.go internal/model/*.go internal/service/*.go

# ② 所有已声明的 enums 注解（仅文档）
grep -rn 'enums:"' internal/dto/*.go internal/model/*.go

# ③ 所有枚举常量（唯一权威来源）
grep -rnE '^\s+\w*(Status|Type|Kind|Level|Method|Channel|Source|Action|Result|Provider|Category|Gender|Obtain)\w*\s*=\s*"' internal/model/*.go

# ④ 找「疑似枚举但未声明」的字段
python - <<'PY'
import re, glob
for f in glob.glob('internal/dto/*.go'):
    src = open(f, encoding='utf-8').read()
    for m in re.finditer(r'^type (\w+(?:Request|Input)) struct \{(.*?)^\}', src, re.M|re.S):
        for ln in m.group(2).split('\n'):
            fm = re.match(r'\s+(\w+)\s+\*?string\s+`([^`]*)`', ln)
            if fm and 'oneof=' not in fm.group(2) and 'enums:' not in fm.group(2):
                if re.search(r'(status|type|kind|method|channel|provider|action|result|category|source)', fm.group(1), re.I):
                    print(f'{m.group(1)}.{fm.group(1)}')
PY
```
