## 严重度定义

| 级别 | 含义 | 例子 |
|---|---|---|
| **P0** | 安全缺陷 / 数据错误 / 提权 / 登出失效 | 越权写、黑名单绕过 |
| **P1** | 契约不符（前端要改） / 业务逻辑错但不涉及安全 | 错误码乱、字段 null、孤儿数据 |
| **P2** | 体验瑕疵 / 一致性问题 / 有替代方案 | 响应包装风格不统一、文档缺枚举 |
| **P3** | 建议 | 哨兵值未标注、命名不统一 |
