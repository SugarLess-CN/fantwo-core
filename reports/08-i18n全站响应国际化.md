## 一、本轮改了什么

### 1.1 新契约（用户明确要求）

```
旧：{"code":200, "message":"操作成功", "data":{...}, "timestamp":..., "path":"..."}
新：{"data":{...}, "message":"Success", "status_code":200}
```

| 变更 | 原因 |
|---|---|
| `code` → `status_code` | 用户指定命名 |
| 删除 `timestamp` / `path` | 前端不需要，日志中间件已记录 |
| message 全英文 | 用户指定「所有响应全部用英文」 |
| data 里的 message 提到顶层 | 用户指定「原先在 data 里面的 message 提取出来」 |
| HTTP 状态 = status_code | 消除「HTTP 200 + code 500」的分裂 |

### 1.2 新增 `internal/pkg/i18n/`（5 个文件，179 个 key）

| 文件 | 内容 |
|---|---|
| `i18n.go` | Key 类型、T/Tf/TIn、ParseLocale、文案表回退（漏配返回裸 key） |
| `keys.go` | 通用 + 各业务域 key（154 个） |
| `keys_extra.go` | 用户域/RBAC/依赖降级补充（17 个） |
| `keys_commerce.go` | 交易/装扮域补充（37 个） |
| `keys_content.go` | 内容/运营域补充（31 个） |
| `keys_message.go` | 消息/审核补充（19 个） |
| `en.go` | 英文文案表（唯一权威，多处 map init 合并） |
| `i18n_test.go` 等三个测试 | 完整性 / 无中文 / 漏配回退 / 抽值锁定 |

### 1.3 `errcode` 重构

`Err` 从持有 `Msg` 字符串 → 持有 `Key i18n.Key` + `Args []interface{}`：

```go
// 改前
ErrNotFound = &Err{Code: 404, HTTP: 404, Msg: "资源不存在"}
// 改后
ErrNotFound = &Err{Code: 404, HTTP: 404, Key: i18n.CommonNotFound}
```

- `Msg()` 方法现场解析文案（RawMsg > Key+Args > 漏配回退）
- `WithKey/WithKeyf` 为推荐入口；`With/Withf` 保留但只接受英文
- `errcode_user.go` 34 条中文 Msg 全部映射到 i18n key

### 1.4 `response` 重构

`Body{Code,Message,Data,Timestamp,Path}` → `Body{Data,Message,StatusCode}`；
新增 `SuccessMsg(c, key, data, args...)`（业务提示提顶层）。

### 1.5 存量文案提取（254 处中文 → 0）

| 执行者 | 域 | 处数 |
|---|---|---|
| `i18n-content` | article/comment/collection/category/tag/banner | 74 |
| `i18n-user` | auth/user/role/points/achievement/invite/report | 74 |
| `i18n-commerce` | payment/order/decoration/emoji（含微信回调） | 118 |
| lead | message/config/audit/storage + ws 网关 + 中间件测试 | 74 |

## 二、功能变化（对前端 / 客户端可见）

| 场景 | 改前响应 | 改后响应 |
|---|---|---|
| 未登录 | `{"code":401,"message":"未登录或登录已过期",...}` | `{"data":null,"message":"Please log in first","status_code":401}` |
| 登录成功 | `{"code":200,"message":"操作成功","data":{...token...}}` | `{"data":{...token...},"message":"Success","status_code":200}` |
| 登出 | `{"code":200,"data":{"success":true,"message":"已退出登录"}}` | `{"data":{"success":true},"message":"Logged out","status_code":200}` |
| 启动期拒写 | `{"code":400,"message":"配置项 s3_bucket 属于启动期配置（中文长段）..."}` | `{"data":null,"message":"Configuration s3_bucket is startup-only (...); change the environment variable and restart instead","status_code":400}` |
| 敏感词增删 | `{"code":200,"data":{"success":true,"message":"敏感词添加成功"}}` | `{"data":{"success":true},"message":"Sensitive word added","status_code":200}` |
| 404 | `{"code":404,"message":"文章不存在"}` | `{"data":null,"message":"Article not found","status_code":404}` |
| 搜索降级 | `{"code":5030,"message":"服务未配置"}` | `{"data":null,"message":"Search service is not configured","status_code":5030}` |

**微信支付回调不变**：`{"code":"SUCCESS","message":"OK"}` —— 微信服务器契约，非本项目响应体。

## 五、遗留与风险

| # | 项 | 说明 |
|---|---|---|
| 1 | **前端契约破坏性变更** | `code`→`status_code`、删 timestamp/path、message 中→英。前端拦截器与文案展示必须同步改。**测试环境已确认不兼容旧前端** |
| 2 | **邮件模板仍是中文** | `auth_service.go` verifyCodeMail 的标题/正文（面向终端用户但非 API message）。待用户裁定：加 `mail.*` key 或切英文模板 |
| 3 | **Swagger 注解未重新生成** | `swagger_types.go` 已更新为新契约，但 `docs/swagger/` 生成物需跑 `swag init` 才会同步 |
| 4 | **Locale 固定英文** | `ParseLocale` 只支持 en，其它语言回退默认。多语言支持需新增 catalogs + Accept-Language 解析（结构已预留） |
| 5 | **存库业务数据仍中文** | 订单标题、积分流水 Description、emoji 分组等——是 data 内容非 message，属历史数据语义，未动（已裁定） |
| 6 | **`bindingMsg` 已英文化** | `ops.go` 的绑定错误提取函数已改为返回英文，全 handler 共用生效 |
