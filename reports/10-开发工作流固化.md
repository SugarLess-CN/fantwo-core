## 附：本轮踩的坑（第 8 个）

用 Python 脚本往 AGENTS.md 插入「标准工作流」章节时：

```python
anchor = '## 约定与陷阱'
s.replace(anchor, workflow + anchor)   # ← anchor 出现两次
```

`'## 约定与陷阱'` 在文中出现两次：一次是章节标题，一次是「第三方优先」条目里的
`本文件 \`## 约定与陷阱\``。`replace` 不限定次数 → workflow 被插入两次，
且第二次把章节标题吞成 `## 约定与陷阱\`，注明候选...`。

**正确做法**：`s.replace(anchor, ..., 1)` 限定次数，或先用 `s.count(anchor) == 1` 断言。

**发现方式**：`grep -n "^## "` 看到章节列表里出现一条 `## 约定与陷阱\`，注明候选、许可证...`
（明显不是标题的残片）。
